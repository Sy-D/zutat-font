# Upstream

Zutat Sans 0.6 is built from Geist source binaries at commit
`10dc7658f13c38a474cde201bb09a4617267545b` of
https://github.com/vercel/geist-font.

Only the Regular, Medium, SemiBold, and Bold upright Sans source binaries are
vendored for reproducible builds. Their original SIL OFL license is preserved.
